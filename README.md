# cc-PortfolioKit

**ノーコードで ── 本当にコードゼロで ── 1 ページのポートフォリオを作る Claude Code プラグイン。**

非エンジニアの方が、HTML も CSS も書かずに自分の自己紹介ページを作れることをゴールにしています。メインで使うコマンドは **`init` / `hearing` / `create` の 3 つ**。脇に補助の `cleanup` と `guide` がもう 2 つあるので、合わせて 5 コマンド構成です。`init` でファイル一式の準備、`hearing` で経歴の聞き取り、`create` で HTML 生成 ── という流れがメイン。`cleanup` は手で Markdown を直したあとの整え役、`guide` は迷ったときの道案内です。

---

## 設計方針

- **メインの 3 コマンド + 補助の 2 コマンド体制**: `init` は最初のセットアップ、`hearing` は経歴の聞き取り、`create` は HTML 生成と編集。`cleanup` は手書き編集の後始末、`guide` は迷ったときのお守り。役割が明確なので、どれを叩くか迷いません
- **対話で完結**: ファイル構造や Markdown の書き方を知らなくても、聞かれたことに答えるだけで OK
- **プロフィールは手編集、経歴は対話**: 氏名・職業・連絡先・自己紹介などはテンプレを開いて自分で書き込む。経歴 ── 本業・副業・活動 ── は数が多くなりやすいので、`hearing` が対話で 1 件ずつ拾ってくれます
- **生成物は 1 ファイル**: 完成品は `portfolio.html` ただ 1 枚。CSS は中に埋め込み済み、JavaScript なし。USB に入れて運んでも、メールで送ってもそのまま開けます

## インストール

Claude Code がすでに入っていれば、次の 1 行で導入できます。

```
/plugin install /Users/your-name/path/to/cc-PortfolioKit
```

パスは、ご自身の環境に合わせて書き換えてください。

### 別の方法: marketplaces に登録する

`~/.claude/settings.json` を開いて、`marketplaces` にこのリポジトリのパスを追加する方法でも構いません。

```json
{
  "marketplaces": [
    "/Users/your-name/path/to/cc-PortfolioKit"
  ]
}
```

これでインストール完了。コマンドが 5 つ増えるだけの、おとなしいプラグインです。

## 使い方

ポートフォリオを作りたいフォルダで、次の 3 ステップだけです。

> 🧭 **道に迷ったら `/cc-portfoliokit:guide`**
>
> 「いま何をすべきか分からない」「久しぶりに使うので忘れた」というときは、`/cc-portfoliokit:guide` を叩いてください。現在のフォルダを覗いて状況を診断し、**次に打つコマンドを 1 つだけ** 教えてくれます。何も書き換えない読み取り専用の道案内なので、気軽にどうぞ。

### ステップ 1 — はじめに 1 回だけ: ファイルとフォルダを用意する

```
/cc-portfoliokit:init
```

このコマンドは、プロジェクト側に **空っぽのテンプレ一式** を用意するだけ。対話ヒアリングはありません。

実行すると次のものが作られ、最後に「これからの流れ」を案内してくれます。

- `./config.md` — サイト全体の設定とサイト用の自己紹介
- `./career/profile.md` — 氏名・職業・趣味などの基本情報
- `./career/work-history.md` — 経歴 (`hearing` で埋まる)
- `./assets/` — アイコン画像を入れるフォルダ
- `./assets/README.md` — assets の使い方ガイド

`init` のあと、ユーザーが手でやることは **2 つだけ**:

1. `./assets/` にアイコン画像を 1 枚入れる ── 顔写真でも似顔絵でも何でも OK
2. `./config.md` と `./career/profile.md` を開いて、プロフィール (氏名・職業・連絡先・自己紹介など) を書き込む

プロフィールはテンプレのコメントに沿って書けば迷わないようにしてあります。`( )` で補足を書かない、`## 見出し` 直下に値を書くだけ、というシンプル構造。

### ステップ 2 — 経歴を対話で集める

```
/cc-portfoliokit:hearing
```

経歴 ── 本業・副業・活動 ── を **対話で 1 件ずつ** 集めて `./career/work-history.md` に書き出します。プロフィールは聞きません ── ステップ 1 の手編集パートに任せます。

実行するとループ式メニューが立ち上がります。

```
次に何を追加しますか?

  ▼ 登録状況
    本業: 0 件
    副業: 0 件
    活動: 0 件

  1) 本業を追加
  2) 副業を追加
  3) 活動を追加
  4) これまでに入れた本業・副業・活動を直す
  5) 終了する
```

`5) 終了する` を選ぶまでループします。1 件追加するごとにメニューに戻るので、本業 → 副業 → 本業 のように自由な順序で追加できます。

#### 本業の聞き方 (二段構造)

本業は **会社単位 + プロジェクト単位** の二段構えです。

- **会社単位**: 会社名 / 在籍期間 / 役職 / ふだんやっていたこと / 会社全体で言える成果
- **プロジェクト単位** (任意): 印象に残った PJ ごとに、PJ 名 / 使ったツール・スキル / 成果 を聞きます ── PJ がたくさんあれば何件でもループ

「印象に残った PJ はない」「営業や店舗スタッフで PJ という単位で動かない」場合は PJ ループをスキップできます。

#### 副業・活動の聞き方 (フラット)

副業と活動は 6 問のフラット構造。案件単位 = 1 件 で完結します。

- **副業**: 案件名 / 期間 / 立場 / ふだんやっていたこと / 使ったツール・スキル / 成果
- **活動**: 活動名 / 期間 / 立ち位置 / ふだんやっていたこと / 関連スキル・道具 / 規模感

質問文は「親しい先輩がカフェで話しかけてくれる感じ」のトーン。任意項目は「思いつかなければ『特になし』で大丈夫」と一言添えて、肩の力を抜いて答えられます。

### ステップ 3 — それ以降ずっと: 作成 / 更新

```
/cc-portfoliokit:create
```

ステップ 1〜2 で素材がそろったら、`create` が「見た目」と「HTML 出力」を担当します。実行タイミングで挙動が変わります。

- **初回 — まだ `portfolio.html` が無いとき**: HTML を作る前に **テーマ方向性ヒアリング** が入り、3 択から選びます ── 「このまま生成 / 決め直したい / イメージがないので提案して」。決め直しを選ぶと、雰囲気 → カラー → サイトタイトル → キャッチコピー → セクション構成 まで対話で決められます。終わったら `portfolio.html` を自動生成
- **2 回目以降 — `portfolio.html` があるとき**: 編集メニューが立ち上がります
  1. **細かい項目を変える** — 氏名・連絡先・職歴などをピンポイント編集
  2. **テーマを決め直したい** — 雰囲気・色・タイトル・キャッチコピーをまとめて見直し
  3. **色だけ変えたい** — テーマカラーとアクセントカラーだけサクッと変更
  4. **再生成だけしたい** — Markdown を手で書き換えたあとに HTML を作り直す
  5. **イメージがない、提案してほしい** — Claude が職歴を読んで案 A / B / C を提示
  6. **キャンセル** — 何もせずに戻る

> 素材がそろっていない状態で `create` を叩いても、ちゃんと「先に `init` / `hearing` をやってね」と案内してくれます。

### おまけ — 手で Markdown を直したあとの「お掃除」: `cleanup`

```
/cc-portfoliokit:cleanup
```

`config.md` / `career/profile.md` / `career/work-history.md` を **手で開いて編集** したあと、必須見出しの欠けや空ブロック・空行の乱れなどがあれば 1 件ずつ確認しながら整えてくれます。HTML には触らないので安心して叩けます。

- **何をする?**: 入力 Markdown 3 ファイルをスキャンして「ちょっと崩れているところ」を一覧表示 → 1 件ずつ「直す / スキップ / 中断」を選びながら直していく
- **何をしない?**: `portfolio.html` の再生成 / 値の意味を変える書き換え / 新項目の提案 ── このあたりは `create` の役目です
- 修正が反映されたら、続けて `/cc-portfoliokit:create` を叩けば HTML に反映されます

## 生成されるファイル構成

```
./
├── config.md                # サイト全体の設定 ── タイトル / テーマカラー / 連絡先 / 自己紹介など
├── career/
│   ├── profile.md           # 氏名・職業・趣味など基本情報。テンプレを手編集
│   └── work-history.md      # 本業 / 副業 / 活動 を 1 件ずつ書いた経歴。hearing で埋まる
├── assets/
│   ├── README.md            # アイコン画像の置き方ガイド
│   └── photo.jpg            # アイコン画像など。ご自身で追加してください
└── portfolio.html           # 完成品 — これがあなたのポートフォリオです
```

> 入力 Markdown は **YAML を使わず、`## 見出し` の下に値を書くだけ** のシンプルな構造です。あとから自分で開いて編集することを最優先に設計してあります。詳しくは `docs/手順書.md` のステップ 5 を参照してください。

## 生成 HTML の特徴

- **1 ファイル完結** — CSS はインライン、JavaScript なし
- **オフライン表示可能** — 外部 CSS や CDN を使わない。顔写真だけ `assets/` 配下を相対パス参照します
- **本業 / 副業 / 活動 を分けて表示** — 経歴セクションはカテゴリごとのサブ見出しで整理されます
- **職業に合わせたラベル** — 「使用技術」「担当業界・商材」「研究分野」など、選んだ職業に合った表示ラベルが自動で適用されます
- **レスポンシブ対応** — スマホでも PC でも崩れない
- **ダークモード自動対応** — 見る人の OS 設定 ── `prefers-color-scheme` ── に合わせて切り替わる

> 🎨 **デザインは専用スキルに分離**: HTML 構造 / CSS / 配色パレット / 職業別ラベル / Markdown 変換 / XSS 対策は、プラグイン内蔵の **`cc-portfoliokit:portfolio-design`** スキル ([`skills/portfolio-design/SKILL.md`](skills/portfolio-design/SKILL.md)) に集約されています。`create` コマンドは HTML 生成のタイミングでこのスキルを呼び出すだけ。**デザインの見た目を変えたい方は、このスキルファイル 1 つを編集すれば全体に反映されます**。
- **印刷時もきれい** — `@media print` で背景色が消えても破綻しない。そのまま履歴書として渡しても恥ずかしくない仕上がり

`portfolio.html` をダブルクリックすればブラウザで開けます。コマンドラインで開きたい派の方はこちら:

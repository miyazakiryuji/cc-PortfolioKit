# assets/

このフォルダには、ポートフォリオで使う画像 ── 顔写真など ── を配置します。

## 顔写真の置き方

1. 顔写真ファイル ── jpg / png / webp などの画像形式です ── をこのフォルダに保存
2. `config.md` を開いて、`## 顔写真のファイル名` ブロック直下の値を保存した相対パスに書き換える。たとえば `assets/photo.jpg` のように
3. `/cc-portfoliokit:create` を実行すると、生成される `portfolio.html` に顔写真が表示されます

> `config.md` は YAML を使わない `## 見出し` 構造です。見出し行 `## 顔写真のファイル名` の下、空行を 1 行はさんだ次の行に書きます。

## 推奨サイズ

- 縦横比は 1:1 の正方形を推奨
- 解像度は 600x600 ~ 1200x1200 程度
- ファイルサイズは 500KB 以下が望ましいです。500KB を超えると `create` 実行時に圧縮を推奨する警告が出ます

> 生成される `portfolio.html` は画像を base64 で埋め込まず、**相対パスで参照** します。つまり完成品を配布するときは `portfolio.html` と `assets/` フォルダをセットでまとめて渡せば、ブラウザでそのまま開けます。

## 他に置けるもの

- ロゴ画像
- プロジェクトのスクリーンショット
- 背景画像。`config.md` から参照する場合に使えます

## 顔写真を載せたくないとき

`config.md` の `## 顔写真のファイル名` ブロックを丸ごと削除すれば OK です。HTML から顔写真が消えます。

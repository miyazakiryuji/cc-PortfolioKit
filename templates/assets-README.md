# assets/

このフォルダには、ポートフォリオで使う画像 (顔写真など) を配置します。

## 顔写真の置き方

1. 顔写真 (jpg / png / webp など) をこのフォルダに保存
2. `config.md` の `photo:` フィールドに相対パス (例: `assets/photo.jpg`) を記入
3. `/cc-portfoliokit:create` を実行すると HTML に埋め込まれます

## 推奨サイズ

- 縦横比は 1:1 (正方形) を推奨
- 解像度は 600x600 ~ 1200x1200 程度
- ファイルサイズは 500KB 以下が望ましい (HTML 生成時に base64 で埋め込まれるため)

## 他に置けるもの

- ロゴ画像
- プロジェクトのスクリーンショット
- 背景画像 (config.md から参照する場合)

# はじめての Claude Code — 「黒い画面? なにそれ?」の方へ

このページは、**Claude Code (クロード コード) をまだ一度も使ったことがない方** のための入門ガイドです。

「**CLI** (シーエルアイ) とか言われても、そもそもそれが何なのか分からない…」という方を想定して、ゼロから順番に書いています。エンジニアでなくても大丈夫。安心して読み進めてください。

> **このページのゴール**
> Claude Code を準備して、`cc-PortfolioKit` プラグインを使えるようになるところまで。
> 実際にポートフォリオを作る手順は、[手順書.md](./手順書.md) のほうにまとまっています。

---

## まずは登場人物の紹介

これから出てくる「初対面の言葉」を、軽く先に並べておきます。今すべて覚える必要はありません。出てきたときに「あ、これか」と思えれば十分です。

| 言葉 | ざっくり意味 |
| --- | --- |
| **Claude Code** | この記事の主役。文章で指示すると、いろいろな作業を手伝ってくれる AI のアプリ。 |
| **CLI (シーエルアイ)** | 黒い画面に文字を打って操作するアプリの形式。日本語にすると「文字で命令する方式」くらいの意味。 |
| **ターミナル / コマンドプロンプト** | その黒い画面そのもの。Mac なら「ターミナル」、Windows なら「コマンドプロンプト」や「PowerShell」。 |
| **コマンド** | 黒い画面に打ち込む「命令の言葉」。Claude Code の中では、`/` (スラッシュ) から始まる短い指示のことを指します。 |
| **プラグイン** | Claude Code に **後付けで機能を足す追加部品**。今回入れる `cc-PortfolioKit` がまさにそれ。 |
| **デスクトップアプリ** | ダブルクリックで起動する、いつものパソコンアプリのこと。黒い画面を一切見なくても使える。 |

「黒い画面」とは、こういうやつです 👇

```
ponchan@MacBook ~ %
```

普段使うアプリと違って、絵もボタンもなく、ただ文字が並んでいるだけの画面。**最初は怖く見えますが、慣れてしまえば普通のチャット欄と変わりません**。

---

## Claude Code には「2 つの顔」がある

Claude Code には、大きく分けて 2 つの使い方があります。

### ① CLI 版 (黒い画面で動くやつ)

ターミナル (黒い画面) を開いて、その中で Claude Code を起動します。**こちらが本来の姿** で、できることが一番多いです。

このページでは、こちらの CLI 版を中心に説明します。

### ② デスクトップアプリ版 (ダブルクリックで開くやつ)

普段のアプリと同じように、アイコンをクリックして起動します。**黒い画面が苦手な方はこちらが入りやすい** です。

デスクトップアプリ版の手順は、別のページに分けてあります 👉 [デスクトップアプリで使う.md](./デスクトップアプリで使う.md)

> **どっちを選べばいい?**
> 迷ったら、まずは **デスクトップアプリ版** から試すのがおすすめです。見た目が普段のアプリと同じなので、心理的なハードルが低いです。
> 「もっと細かく使いこなしたい」と思ったタイミングで CLI 版に移行しても全然遅くないので、安心してください。

## ステップ 1: Claude Code をインストールする

「インストール」とは、**パソコンにアプリを入れる作業** のこと。スマホで言うところの「アプリをダウンロードして使えるようにする」と同じです。

### 1-1. 公式サイトを開く

ブラウザ (Chrome や Safari など、いつもインターネットを見るときに使うアプリ) で **「Claude Code」** と検索してください。

検索結果の一番上に出てくる **Anthropic (アンソロピック) 社の公式ページ** を開きます。Anthropic は Claude を作っている会社の名前です。

> **怪しいサイトを開かないコツ**
> URL (アドレス) に `anthropic.com` という文字が入っているかを確認してください。それ以外の似たような名前のサイトは、念のため避けたほうが無難です。

### 1-2. 「CLI 版」と「デスクトップアプリ版」のどちらをインストールするか決める

公式サイトには、CLI 版・デスクトップアプリ版の両方の案内があります。

- **CLI 版を選ぶ場合** → このページを続けて読んでください。
- **デスクトップアプリ版を選ぶ場合** → [デスクトップアプリで使う.md](./デスクトップアプリで使う.md) に切り替えてください。

### 1-3. 案内に沿ってインストール

公式サイトのインストール手順に沿って進めてください。Claude Code のインストール方法は時々アップデートされるので、**ここで具体的な手順を書くより、公式の最新案内に従ったほうが確実です**。

> **インストール中に英語のメッセージが出てきても落ち着いて**
> 「許可してもいいですか?」「パスワードを入力してください」のようなメッセージが英語で出ることがあります。慌てず、書かれている内容を翻訳ツールに貼り付けて確認すれば大丈夫です。

## ステップ 2: ターミナル (黒い画面) を開く

CLI 版を使う場合、ターミナルが必要です。デスクトップアプリ版だけ使う方は、このセクションは飛ばしてください。

### Mac の場合

1. キーボードで **`Command` + `Space`** を同時に押す
2. 出てきた検索欄に **`ターミナル`** と入力
3. **「ターミナル」アプリ** をクリック (黒い四角に白い `>_` が描かれているアイコンです)

### Windows の場合

1. 画面左下の **検索欄** (虫眼鏡のアイコン) をクリック
2. **`コマンドプロンプト`** または **`PowerShell`** と入力
3. 出てきたアプリをクリック

> **「黒い画面が出てきた…!」**
> はい、それで合っています。これからこの画面に文字を入力していきます。
> ちなみに、誤って何か文字を打ってしまっても、たいていは `Enter` を押さない限り何も起きません。気軽に試してみてください。

---

## ステップ 3: Claude Code を起動する

ターミナルが開けたら、次の文字を入力して `Enter` キーを押します。

```
claude
```

これだけ。たった 6 文字です。

> **入力するときの注意**
> - 半角英数字で入力します (全角の「ｃｌａｕｄｅ」では動きません)。
> - 最後の `Enter` を忘れずに。
>
> **「コマンドが見つかりません」のような英語が出る場合**
> インストールが正しく完了していない可能性が高いです。[トラブルシューティング](./トラブルシューティング.md) の「Claude Code が起動しない」のセクションを見てください。

Claude Code が起動すると、画面が切り替わって入力待ち状態になります。**ここからは普通のチャットアプリとほぼ同じ感覚で使えます**。「こんにちは」と打って `Enter` してみると、返事をしてくれます。

## ステップ 4: 作業するフォルダに移動する

Claude Code を使うときは、「**どのフォルダで作業するか**」をあらかじめ決めておくと迷いません。

たとえば、デスクトップに **「マイポートフォリオ」** という名前のフォルダを作っておいて、そこを作業場所にする、というふうにします。

### 4-1. フォルダを用意する

普段どおりの操作で、デスクトップに新しいフォルダを作ってください。

- **Mac**: デスクトップで右クリック → 「新規フォルダ」
- **Windows**: デスクトップで右クリック → 「新規作成」→「フォルダー」

名前は分かりやすいもの (例: `マイポートフォリオ`) にします。日本語でも大丈夫ですが、**スペースや記号は避けたほうが無難** です。

### 4-2. Claude Code でそのフォルダに移動する

Claude Code が起動した状態で、こう伝えるだけで OK です。

```
デスクトップの「マイポートフォリオ」フォルダで作業したいです
```

Claude Code がフォルダを切り替えてくれます。

> **コマンドで自分で移動したい派の方へ (オプション)**
> ターミナルに直接 `cd` (チェンジ ディレクトリ = フォルダ移動の命令) を打って移動することもできます。たとえば Mac なら:
> ```
> cd ~/Desktop/マイポートフォリオ
> ```
> こだわらない方は、Claude Code に日本語でお願いするだけで十分です。

## ステップ 5: プラグインをインストールする

ここからが本題。**`cc-PortfolioKit` プラグイン** を Claude Code に入れます。

### 5-1. プラグインって何だっけ?

Claude Code 本体に、**後から機能を追加できる「拡張パーツ」** のことです。スマホで言えば「アプリの中のアドオン」、車で言えば「カスタムパーツ」みたいなものです。

`cc-PortfolioKit` を入れると、`/cc-portfoliokit:create` という新しいコマンドが使えるようになります。

### 5-2. インストールの方法

Claude Code の画面で、次のように入力します。

```
/plugin install /Users/あなたのユーザー名/Developer/work/Idris-co/tools/cc-PortfolioKit
```

> **`あなたのユーザー名` の部分**
> ここは **自分のパソコンのユーザー名** に書き換えてください。Mac なら、ターミナルの左側に表示されている名前です (たとえば `ponchan` とか)。
>
> パスが分からないときは、Claude Code に「cc-PortfolioKit のフォルダはどこにありますか?」と聞いてみると教えてくれます。

入力して `Enter` すると、「プラグインを追加しました」というメッセージが出ます。

> **「プラグインを追加しました」が出ない場合**
> パスが間違っているか、フォルダが存在しないかのどちらかです。[トラブルシューティング](./トラブルシューティング.md) の「プラグインがインストールできない」を確認してください。

## ステップ 6: 使ってみる

ここまで来たら、もう準備は完了です。

このプラグインで覚える呪文 (コマンド) は **2 つだけ** です。

| コマンド | 何をする? | いつ叩く? |
| --- | --- | --- |
| `/cc-portfoliokit:init` | フォルダを作って、お名前と職歴を **対話形式でヒアリング** して保存する | **最初の 1 回だけ** |
| `/cc-portfoliokit:create` | 保存された内容から `portfolio.html` を作る / 直す | **`init` のあと、何回でも** |

「`init` (イニット) は最初の 1 回、`create` (クリエイト) は永遠に」 — このリズムで覚えてください。

まずは Claude Code の入力欄で、

```
/cc-portfoliokit:init
```

を打って送信してみましょう。あとは画面に表示される質問に答えていくだけで、土台が整います。続いて、

```
/cc-portfoliokit:create
```

を実行すれば、`portfolio.html` が出来上がります。

その先の詳しい流れは [手順書.md](./手順書.md) にまとまっています。

## ちょっとだけ覚えておきたい「便利キー」

ターミナルや Claude Code を使う中で、たまに必要になるキー操作を載せておきます。

| やりたいこと | キー操作 |
| --- | --- |
| 前に打ったコマンドをもう一度出す | **`↑` (上矢印)** |
| 入力中の行をぜんぶ消す | **`Ctrl` + `U`** |
| いまの操作をやめる (途中で止める) | **`Ctrl` + `C`** |
| Claude Code を完全に終了する | **`Ctrl` + `D`** または `exit` と入力して `Enter` |
| 画面の文字をコピーする (Mac) | マウスで範囲選択 → **`Command` + `C`** |
| 画面の文字をコピーする (Windows) | マウスで範囲選択 → **右クリック** または `Ctrl` + `Shift` + `C` |

> **`Ctrl` + `C` は「中止」、`Command` + `C` は「コピー」**
> ややこしいですが、ターミナル世界では `Ctrl` + `C` はコピーではなく「いま動いている処理を止める」という意味です。
> 何かが止まらなくなったときは、深呼吸して `Ctrl` + `C` を 1 〜 2 回押してみてください。

## それでもよく分からないとき

正直に申し上げると、**最初の数回はうまくいかなくて当たり前** です。世界中のエンジニアが、初めて黒い画面を見たときに同じように戸惑っています。

うまくいかないときは、

1. 一回 Claude Code を **`Ctrl` + `D`** で終了
2. もう一度ターミナルから `claude` で起動
3. 「いまこういう状態で、こうしたかったんですが、こうなってしまいました」と **状況をそのまま日本語で説明**

これでたいてい解決します。Claude Code は **困っている人を助けるのが本業** のような AI なので、遠慮せず頼ってください。

エラーメッセージが出た場合は、[トラブルシューティング.md](./トラブルシューティング.md) も合わせて見てみると、よくあるパターンの解説が見つかるかもしれません。

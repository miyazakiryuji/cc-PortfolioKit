# cc-PortfolioKit のつかい方 — はじめての方へ

「自分のホームページがほしいけど、HTML とか CSS とか言われた瞬間に画面を閉じたくなる」… そんな方のために cc-PortfolioKit はあります。

このページでは、専門用語をできるだけ使わずに (使う場合は必ず一言添えながら)、最初から順を追ってご案内します。読み飛ばしてもいいですが、上から順に進める方が迷子になりにくいです。お茶でも淹れて、のんびりやりましょう。

> **読み始める前にチェック**
>
> - **「Claude Code をまだインストールしていない」「黒い画面 (CLI) が初めて」** という方は、先に [はじめてのClaude Code.md](./はじめてのClaude%20Code.md) で準備を整えてから戻ってきてください。
> - **「黒い画面はちょっと…」と思った方** は、[デスクトップアプリで使う.md](./デスクトップアプリで使う.md) のほうが入りやすいです。
> - **エラーが出てしまった** ときは、[トラブルシューティング.md](./トラブルシューティング.md) に駆け込めば、よくあるパターンの解消法が並んでいます。

---

## このプラグインで何ができるの?

ざっくり言うと:

- **お名前 / 職歴 / 在籍年数 / どんな業務をしたか** などを質問形式で答えていくと
- **1 ページの自己紹介サイト (HTML ファイル)** が自動でできあがります

それだけです。デザインのセンスも、プログラミングの知識も要りません。
完成したファイルは、メールに添付して送ったり、ホームページとして公開したり、紙に印刷して履歴書代わりに使ったりできます。

> **HTML ファイルって?** Chrome や Safari でいつも見ているホームページの素になるファイルのことです。完成したファイルをダブルクリックすると、ブラウザで自分のページが開きます。

---

## 言葉の説明 (はじめに少しだけ)

このページに出てくる単語を、先にざっと整理しておきます。全部覚える必要はありません。「あれ、これ何だっけ」と思ったときに戻ってくる用の早見表です。

| 言葉 | これだけ知っていれば OK |
| --- | --- |
| **コマンド** | Claude Code に「これやって」とお願いするための呪文。`/` (スラッシュ) から始まる文字を入力します。 |
| **フォルダ** | パソコンの中で、ファイルをまとめておく入れ物。デスクトップにある、あの黄色いアイコンのやつです。 |
| **HTML ファイル** | ブラウザで開ける、ホームページの形のファイル。 |
| **Markdown (マークダウン)** | 文章を書くときの簡単なルール。記号をちょっと付けるだけで見出しや箇条書きが書けます。Word よりずっと素朴です。 |
| **テンプレート** | 「ひな型」のこと。穴埋めするだけで完成する、料理キットみたいな下書きです。 |

## 必要なもの (準備)

3 つだけ揃っていれば OK です。

1. **Claude Code** がパソコンに入っていること
   - (まだの方は Claude Code 公式のインストール手順をどうぞ)
2. **cc-PortfolioKit プラグイン** が入っていること
   - インストールのやり方は README に書いてあります
3. **作業用のフォルダ** が 1 つあること
   - 場所はどこでも OK。ここでは例として、デスクトップに「**マイポートフォリオ**」というフォルダを作ったと仮定して進めます

> もしフォルダの作り方が分からなければ、Claude Code に「デスクトップに『マイポートフォリオ』というフォルダを作って」とお願いしてみてください。代わりに作ってくれます。

## このプラグインのコマンド

メインで使うのは 2 つ、+ いざというときの道案内コマンドが 1 つです。

| コマンド | 何をする? | いつ叩く? |
| --- | --- | --- |
| `/cc-portfoliokit:init` | フォルダを作りつつ、お名前と職歴を **対話形式でヒアリング** して保存する | **最初の 1 回だけ** |
| `/cc-portfoliokit:create` | 保存された内容から `portfolio.html` を作る / 直す | **`init` のあと、何回でも** |
| `/cc-portfoliokit:guide` | いまの状況を診断して、次に打つべきコマンドを 1 つだけ教えてくれる道案内 | **道に迷ったらいつでも** |

> 「ふだん使い」はずっと `create` だけです。`init` のことは 1 回やったら忘れてもらって構いません。
>
> 🧭 **「あれ、何やればいいんだっけ?」となったら**、深く考えずに `/cc-portfoliokit:guide` を叩いてみてください。何も書き換えずに、現状確認と次の一手を教えてくれます。お守りみたいなコマンドです。

## ステップ 1: はじめてのセットアップ (`init`)

### 1-1. Claude Code を起動する

いつもの方法で開いてください。

### 1-2. 作業フォルダに移動する

Claude Code の入力欄に、次のように打って送信します。

```
さきほど作った「マイポートフォリオ」フォルダに移動してください
```

これで作業場所が切り替わります。

> **うまくいかないとき:** 「デスクトップにある『マイポートフォリオ』フォルダはどこ?」と Claude Code に聞いてみてください。一緒に探してくれます。気軽に頼って大丈夫です。

### 1-3. セットアップのコマンドを唱える

次の文字をそのまま入力 (またはコピペ) して送信します。

```
/cc-portfoliokit:init
```

`init` (イニット) は「**初期化する**」の略。最初の 1 回だけ叩く呪文です。

### 1-4. 質問に答える

Claude Code が、順番に次のようなことを聞いてきます。質問は **大きく 4 ブロック** に分かれていて、後ろの 2 つ (副業・活動) は「ない方は丸ごとスキップ」できます。

**① お名前まわり**

1. **お名前 (フルネーム)** — 例:「山田 太郎」
2. **ふりがな** — 例:「やまだ たろう」 (スキップでも OK)
3. **英語表記** — 例:「Taro Yamada」 (スキップでも OK)
4. **これまでのキャリアは合計で何年くらいですか?** — 例:「8 年」

**② 本業 (これまで所属してきた会社・組織) — 1 社ずつ**

5. **本業の職歴を新しい順 / 古い順、どちらで聞いていきましょうか?**
6. **会社名** — 例:「株式会社サンプル」
7. **在籍期間** — 例:「3 年」「2020-04 〜 2023-03」「現在も在籍中」など、書きやすい形で OK
8. **役職や肩書き** (スキップでも OK)
9. **そこで具体的にどんな業務をされましたか?** — 主なものを 3〜5 個、箇条書き感覚で
10. **使っていた技術** (スキップでも OK)
11. **数字で言える成果** — 例:「レスポンス時間を 50% 改善」 (スキップでも OK)
12. **もう 1 社追加しますか?** — Yes / No で答えるだけ。Yes なら 6 番に戻ります

**③ 副業 (業務委託・フリーランス・個人開発・顧問など) — 任意**

13. **副業はありますか?** — **ないなら「なし」と答えるだけ** でまるごとスキップ
14. ある方は、本業と同じ要領で 1 件ずつヒアリング (案件名 / 期間 / 立場 / 業務内容 / 技術 / 成果)
15. **もう 1 件追加しますか?**

**④ 活動 (イベント運営・登壇・OSS・執筆など) — 任意**

16. **活動はありますか?** — お金が動かないものも含めて OK。**ないなら「なし」と答えるだけ**
17. ある方は、1 件ずつヒアリング (活動名 / 期間 / 役割 / 内容 / 関連スキル / 成果)
18. **もう 1 件追加しますか?**

> ここでは完璧主義は敵です。「**スキップでも OK** と言われたところは堂々とスキップ」「副業も活動も無ければ堂々と『なし』」が正解です。後から何度でも直せます。

### 1-5. セットアップ完了の確認

ヒアリングが終わると、Claude Code が「セットアップが完了しました!」と報告してくれます。フォルダの中はこうなっているはずです。

```
マイポートフォリオ/
├── config.md
├── career/
│   ├── profile.md      ← 答えた「お名前 / キャリア年数」がここに入っています
│   └── work-history.md ← 答えた「職歴」がここに入っています
├── assets/
│   └── README.md
```

`portfolio.html` (完成品) は **まだ作られていません**。次のステップで作ります。

## ステップ 2: ポートフォリオを完成させる (`create`)

### 2-1. `create` のコマンドを唱える

次の文字を打って送信します。

```
/cc-portfoliokit:create
```

これが、初回も 2 回目以降もずっと使う「ふだん使いのコマンド」です。

### 2-2. テーマの雰囲気をちょっとだけ相談される

`create` を初めて叩くと、いきなり HTML ができるのではなく、まず **「どんな雰囲気のポートフォリオにしたいですか?」** と Claude Code が声をかけてくれます。3 つの選択肢が出るので、気軽に選んでください。

| 番号 | やること | こんな方向け |
| --- | --- | --- |
| 1 | **このまま生成する** | とにかく早く完成したい方。テンプレートの初期色 (青系) で OK |
| 2 | **テーマを決め直したい** | 色や雰囲気を自分で決めたい方 |
| 3 | **イメージがない** | 「こんな感じ」と言葉にできない方。Claude Code から案を提案してもらえます |

> **急ぎの方は「1) このまま」で構いません**。あとから何度でも変えられます。完璧に決めなくて大丈夫。

**「2) テーマを決め直したい」を選んだ場合** は、Claude Code が以下を順番に聞いてくれます。1 問ずつ短く答えるだけなので、心の準備は要りません。

- どんな雰囲気にしたい? (落ち着き / カジュアル / クリエイティブ / シンプル / ダーク / 自由記入)
- 色はどれにする? (雰囲気に合わせた候補が出ます。HEX で自分で指定することも可能)
- サイトタイトルは? (こちらから候補が出るので選ぶだけでも OK)
- キャッチコピーは? (こちらも候補つき)
- どのセクションをどの順番で出す? (今のままで良ければそう答えるだけ)

**「3) イメージがない」を選んだ場合** は、職歴の内容を Claude Code が読んで、`案 A` `案 B` `案 C` のように **方向性ごとセット** で提案してくれます。気に入ったものを選ぶだけ。「もう少しこういう感じが…」と言えば、その方向で再提案もしてくれます。

### 2-3. ポートフォリオが生成される

雰囲気の相談が終わると、`portfolio.html` が自動でできあがります。「`✅ portfolio.html を生成しました!`」というメッセージが出ればゴールです。

### 2-4. 完成を確認する

フォルダの中に **`portfolio.html`** という出来たてホヤホヤのポートフォリオファイルがあるはずです。

> **早く見たい方は:** `portfolio.html` をダブルクリック。ブラウザで自分のページがお披露目されます。

---

## ステップ 3: あとから直したくなったら (`create` をもう一度)

「やっぱり職歴を 1 つ追加したい」「色を変えたい」と思ったら、もう一度 `create` を叩くだけです。

### 3-1. 同じコマンドを叩く

```
/cc-portfoliokit:create
```

### 3-2. 編集メニューが出る

Claude Code が「**お、すでにポートフォリオがありますね。どこを直しましょう?**」と気づいてくれます。

> **メモ:** コマンド名は `create` (作る) ですが、2 回目以降は自動で **編集モード** に切り替わります。「`init` は最初の 1 回、`create` は永遠に」と覚えてください。

### 3-3. やりたいことを選ぶ

Claude Code が、まず **6 つの大きな選択肢** を出してくれます。「全部やり直す」「ちょっとだけ変える」「とにかく提案して」などをここで選びます。

| 番号 | やりたいこと | こんなときに |
| --- | --- | --- |
| 1 | **細かい項目を変えたい** | 氏名・連絡先・職歴など、ピンポイントで直したいとき |
| 2 | **テーマを決め直したい** | 雰囲気・色・タイトル・キャッチコピーをまとめて見直したいとき |
| 3 | **色だけ変えたい** | テーマカラーとアクセントカラーだけサクッと変えたいとき |
| 4 | **内容を変えずに再生成だけしたい** | 自分で Markdown を書き換えた後に、HTML だけ作り直したいとき |
| 5 | **イメージがない、提案してほしい** | 「変えたいけど何を変えたいか言葉にできない」とき |
| 6 | **キャンセル** | やっぱりやめたとき |

> **迷ったら 5 番** が安心です。Claude Code が職歴を読んで「こんな方向性はいかがですか?」と **案 A / B / C** を出してくれます。気に入ったものを選ぶだけ。

**「1) 細かい項目を変えたい」を選んだ場合**、さらに細かいメニューが出てきます。よく使うのはこのあたり:

- サイトタイトル / キャッチコピーを変える
- テーマカラーを変える
- 自己紹介 (About) を直す
- 氏名・ふりがな・キャリア総年数を直す
- 連絡先 (Email / GitHub など) を直す
- 顔写真のファイル名を変える
- **経歴を追加する** (本業 / 副業 / 活動 から選んで追加)
- **既存の経歴を直す** (本業 ↔ 副業 ↔ 活動 の種別変更も可能)

直したい項目を選ぶと、その項目について質問が始まります。

> **「2) テーマを決め直したい」「3) 色だけ変えたい」を選んだ場合** は、ステップ 2-2 で出てきた「雰囲気のヒアリング」と同じ流れで色や方向性を決め直せます。同じ手順なので、初回と 2 回目で迷うことはありません。

### 3-4. 反映を確認する

選んだ項目について答えると、`portfolio.html` が **その場で作り直されます**。

ブラウザで `portfolio.html` を再読み込み (リロード) すれば、新しい内容が見られます。「あれ、さっきと違う!」となれば成功です。

## ステップ 4: できたページを見てみる

1. 作業フォルダ (「マイポートフォリオ」) を開く
2. **`portfolio.html`** をダブルクリック
3. ブラウザ (Chrome / Safari など) でポートフォリオがお披露目

> **誰かに見せたいとき:** ファイルをそのままメールに添付して送って OK です。ホームページとして公開する方法もあります (これは別のページで案内します)。

## ステップ 5 (寄り道): Markdown を自分で開いて編集する

ここまでで完成、なのですが — 「**もう少し細かく自分でいじりたい**」「**たくさん書き換えるからメニューを 1 つずつ選ぶのが面倒**」という方のために、もう一つの編集方法があります。それが「**フォルダの中の `.md` ファイルを直接開いて書き換える**」というやり方。

> 「Markdown ってあれでしょ? 文字に印を付ける記号がいっぱいのやつ…」と身構える必要はありません。cc-PortfolioKit の `.md` ファイルは、**普通の文章の前に「## なになに」という見出しを書いてあるだけ**です。Word の見出しスタイルに似たものだと思ってください。

### 5-1. 編集できるファイルは 3 つ

```
マイポートフォリオ/
├── config.md                  ← サイトのタイトル / 色 / 自己紹介 / 連絡先など
└── career/
    ├── profile.md             ← 氏名 / ふりがな / キャリア総年数
    └── work-history.md        ← 職歴 (1 社ごとに分かれて並んでいる)
```

メモ帳 / TextEdit / VS Code など、**普段使っている文字編集アプリ**で開いて構いません。慣れたアプリでどうぞ。

### 5-2. ファイルの中身はこんな見た目

たとえば `career/profile.md` の中はこうなっています:

```markdown
## 氏名

山田 太郎

## ふりがな

やまだ たろう

## キャリア総年数

5 年
```

ルールは 3 つだけ:

1. **「## なになに」(シャープ 2 つ + スペース + ラベル) の下に、値を書く**
2. **見出しと値の間は 1 行空ける**
3. **`<!-- -->` で囲まれた部分はパソコン向けのメモ書き** (画面には出ないので無視して OK)

### 5-3. 項目を「足す」「消す」「並べ替える」

cc-PortfolioKit の `.md` ファイルは、**「## なになに」のブロック単位** で動かせるように作ってあります。

**消したいとき** — その「## なになに」の行から、次の「## なになに」の手前までを **まるごと削除** すれば OK。たとえば「ふりがな」を載せたくないなら:

```markdown
## ふりがな        ← この行から

やまだ たろう       ← ここまで削除

<!-- 不要なら、... --> ← コメントも一緒に削除
```

これで「ふりがな」は HTML に出なくなります。

**足したいとき** — 好きな場所に「## 新しい項目名」を追加して、下に値を書くだけ。たとえば居住地を入れたければ:

```markdown
## 居住地

東京都
```

を、profile.md の好きな場所に差し込んで保存。

**並べ替えたいとき** — 「## なになに」のブロックごと、上下に切り貼り。HTML 上の表示順も、書いた順番に合わせて並びます。

### 5-4. 職歴 (work-history.md) の構造

職歴ファイルはちょっとだけ階層が深いです。**1 社ごとに `## 会社名` のブロック**があり、その中に `### 期間` `### 役職` `### やったこと` などの **`### ` 見出し (シャープ 3 つ) のサブブロック** が並んでいます。

```markdown
## 株式会社サンプル

### 期間

2020-04 〜 2023-03 (3 年)

### 役職

ソフトウェアエンジニア

### やったこと

- 〇〇プロダクトの開発
- レビュー業務
```

ルールは profile.md と同じ。

- **会社を 1 社追加** したい → 好きな位置に `## 新しい会社名` のブロックをコピペして書き換える
- **会社を消す** → その `## 会社名` から次の `## 会社名` の手前までを丸ごと削除
- **「使用技術」だけ消したい** → その会社の `### 使用技術` ブロックだけを削除

> ファイルの末尾には「コピペ用のひな型」がコメントで残してあります。新しい職歴を足すときはそれを使うとラクです。

### 5-5. 保存したら `/cc-portfoliokit:create`

編集が終わったら、Claude Code に戻って **`/cc-portfoliokit:create`** を叩くだけ。「編集メニュー」が出るので **「1) 再生成」を選択** すると、書き換えた内容が `portfolio.html` に反映されます。

> **ヒント:** ファイルを開きながら少しずつ書き換えて、ブラウザで `portfolio.html` をリロードしながら確認すると、自分のページが目の前で育っていく感覚があって楽しいですよ。

## こんなときどうする? (よくある質問)

### Q0. そもそも何から始めればいいか分からない

迷ったらまず `/cc-portfoliokit:guide` を叩いてください。フォルダの中を覗いて、いまの状況に合わせて「次に打つコマンドを 1 つだけ」教えてくれます。何も書き換えない読み取り専用の道案内なので、気軽に試して大丈夫です。

### Q1. コマンドを打ったのに何も起きない

- スペルが間違っていないか確認してください。正しいコマンドは `/cc-portfoliokit:init` と `/cc-portfoliokit:create` です (`:` を忘れがちです)
- 半角で入力されているか確認してください。全角の `/` だと反応してくれません

### Q2. `create` を打ったら「先に init をやってね」と言われた

そのとおりです。**最初の 1 回だけ** `/cc-portfoliokit:init` を実行する必要があります。ヒアリングが終わったら、もう一度 `/cc-portfoliokit:create` を叩いてください。

### Q3. 質問の意味が分からない

そのまま **「分かりません」「もう少し簡単に説明して」** と Claude Code に伝えてください。別の言い方で説明し直してくれます。恥ずかしがる必要はありません、Claude Code は何度聞かれてもニコニコしています。

### Q4. 途中でやめたくなった

- 質問の途中なら「いったん中断します」と打てば止まります
- 入力ずみの内容は自動で保存されているので、次に同じコマンドを実行すれば続きから再開できます

### Q5. 変な内容を入力してしまった

慌てなくて大丈夫です。もう一度 `/cc-portfoliokit:create` を実行して編集メニューに入り、書き換えるだけ。何度でもやり直せます。

### Q6. ポートフォリオが見つからない

「`portfolio.html` というファイルはどこにある?」と Claude Code に聞いてください。すぐに教えてくれます。

### Q7. 顔写真を入れたい

1. 顔写真ファイル (JPG / PNG など) を、作業フォルダの中の **`assets`** フォルダに入れる
2. もう一度 `/cc-portfoliokit:create` を実行し、編集メニューから「顔写真のファイル名」を選んで設定する

詳しくは `templates/assets-README.md` も参考にしてください。

### Q8. `init` をもう一度やり直したい

`/cc-portfoliokit:init` をもう一度叩くと、「既にファイルがありますがどうしますか?」と聞いてくれます。

- **足りないものだけ作る** (推奨) — 編集済みの内容は守られます
- **全部上書きしてやり直す** — 注意: 書いた内容が消えます

### Q9. 副業や活動は必ず入れないとダメ?

いいえ、両方とも任意です。`init` の途中で「副業はありますか?」「活動はありますか?」と聞かれたとき、**「なし」と答えればまるごとスキップ** されます。あとから思いついたら、`/cc-portfoliokit:create` の編集メニューから「経歴を追加する」を選んで本業 / 副業 / 活動のどれでも追加できます。

### Q10. 本業 / 副業 / 活動 の違いがよく分からない

ざっくり次の感覚で大丈夫です。迷ったら「自分が一番しっくりくる方」で選んでください (あとで変えられます)。

- **本業**: フルタイムで所属している (していた) 会社・組織
- **副業**: 業務委託・フリーランス・個人開発・顧問など、**本業以外でお金が動く** 取り組み
- **活動**: イベント運営・コミュニティ活動・OSS・登壇・執筆など、**お金が直接動かなくても胸を張れる取り組み**

## それでも困ったら

このページで解決しない場合は、**Claude Code にそのまま「困っています」と伝えて** ください。状況を一緒に整理しながら手助けしてくれます。

「うまくいかないこと自体を、そのまま言葉にして伝える」のがいちばんの近道です。たとえば:

- 「`/cc-portfoliokit:create` と入力したら、`〇〇` というメッセージが出て先に進めません」
- 「ポートフォリオはできたのですが、ブラウザで開いたら真っ白でした」

このように **何をして、何が起きたか** をセットで伝えると、Claude Code がすぐに原因を一緒に探してくれます。

> エンジニアの世界には「**現象を正確に説明できれば、問題は半分解けたようなもの**」という言い回しがあります。安心して、何が起きたかをそのまま教えてください。

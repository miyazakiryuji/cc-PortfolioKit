# cc-PortfolioKit のつかい方 — はじめての方へ

「自分のホームページがほしいけど、HTML とか CSS とか言われた瞬間に画面を閉じたくなる」… そんな方のために cc-PortfolioKit はあります。

このページでは、専門用語をできるだけ使わずに ── 使う場合は必ず一言添えながら ── 最初から順を追ってご案内します。読み飛ばしてもいいですが、上から順に進める方が迷子になりにくいです。お茶でも淹れて、のんびりやりましょう。

> **読み始める前にチェック**
>
> - **「Claude Code をまだインストールしていない」「黒い画面 ── CLI と呼ばれる文字入力画面のこと ── が初めて」** という方は、先に [はじめてのClaude Code.md](./はじめてのClaude%20Code.md) で準備を整えてから戻ってきてください。
> - **「黒い画面はちょっと…」と思った方** は、[デスクトップアプリで使う.md](./デスクトップアプリで使う.md) のほうが入りやすいです。
> - **エラーが出てしまった** ときは、[トラブルシューティング.md](./トラブルシューティング.md) に駆け込めば、よくあるパターンの解消法が並んでいます。

---

## このプラグインで何ができるの?

ざっくり言うと:

- **お名前や職業はファイルに自分で書き込み**、**職歴・副業・活動は対話で答えて** いくと
- **1 ページの自己紹介サイト ── つまり HTML ファイル ── が** 自動でできあがります

それだけです。デザインのセンスも、プログラミングの知識も要りません。
完成したファイルは、メールに添付して送ったり、ホームページとして公開したり、紙に印刷して履歴書代わりに使ったりできます。

> **流れの全体像**:
>   1. `/cc-portfoliokit:init` でファイルとフォルダを用意
>   2. `./assets/` フォルダにアイコン画像を 1 枚入れる
>   3. `./config.md` と `./career/profile.md` を開いてプロフィールを書き込む
>   4. `/cc-portfoliokit:hearing` で職歴・副業・活動を対話で聞いてもらう
>   5. `/cc-portfoliokit:create` で HTML を作る

> **HTML ファイルって?** Chrome や Safari でいつも見ているホームページの素になるファイルのことです。完成したファイルをダブルクリックすると、ブラウザで自分のページが開きます。

## 言葉の説明 — はじめに少しだけ

このページに出てくる単語を、先にざっと整理しておきます。全部覚える必要はありません。「あれ、これ何だっけ」と思ったときに戻ってくる用の早見表です。

| 言葉 | これだけ知っていれば OK |
| --- | --- |
| **コマンド** | Claude Code に「これやって」とお願いするための呪文。スラッシュ記号 `/` から始まる文字を入力します。 |
| **フォルダ** | パソコンの中で、ファイルをまとめておく入れ物。デスクトップにある、あの黄色いアイコンのやつです。 |
| **HTML ファイル** | ブラウザで開ける、ホームページの形のファイル。 |
| **Markdown** | マークダウンと読みます。文章を書くときの簡単なルールで、記号をちょっと付けるだけで見出しや箇条書きが書けます。Word よりずっと素朴です。 |
| **テンプレート** | 「ひな型」のこと。穴埋めするだけで完成する、料理キットみたいな下書きです。 |

---

## 必要なもの — 準備

3 つだけ揃っていれば OK です。

1. **Claude Code** がパソコンに入っていること
   - まだの方は Claude Code 公式のインストール手順をどうぞ
2. **cc-PortfolioKit プラグイン** が入っていること
   - インストールのやり方は README に書いてあります
3. **作業用のフォルダ** が 1 つあること
   - 場所はどこでも OK。ここでは例として、デスクトップに「**マイポートフォリオ**」というフォルダを作ったと仮定して進めます

> もしフォルダの作り方が分からなければ、Claude Code に「デスクトップに『マイポートフォリオ』というフォルダを作って」とお願いしてみてください。代わりに作ってくれます。

## このプラグインのコマンド

メインで使うのは 3 つ、+ 補助のコマンドが 2 つです。

| コマンド | 何をする? | いつ叩く? |
| --- | --- | --- |
| `/cc-portfoliokit:init` | フォルダとファイルを用意して、これからの流れを案内する | **最初の 1 回だけ** |
| `/cc-portfoliokit:hearing` | 職歴・副業・活動を **対話形式で 1 件ずつヒアリング** して `career/work-history.md` に書く | **プロフィールを書いた後、何度でも** |
| `/cc-portfoliokit:create` | 保存された内容から `portfolio.html` を作る / 直す | **素材がそろったら、何度でも** |
| `/cc-portfoliokit:cleanup` | 手で書き換えた Markdown の **形が崩れていないか確認** して、1 件ずつ整える | **Markdown を手で直したあと** |
| `/cc-portfoliokit:guide` | いまの状況を診断して、次に打つべきコマンドを 1 つだけ教えてくれる道案内 | **道に迷ったらいつでも** |

> **ふだん使い**は `hearing` と `create` の 2 つ。`init` は 1 回やったら忘れてもらって構いません。
>
> 🧹 **`cleanup` は手書き編集のお掃除役**。`config.md` などをメモ帳で直接書き換えたあと、見出しを消し忘れたり値が抜けたりしていないかを確認したいときに叩きます。HTML には触らないので、安心して気軽にどうぞ。
>
> 🧭 **「あれ、何やればいいんだっけ?」となったら**、深く考えずに `/cc-portfoliokit:guide` を叩いてみてください。何も書き換えずに、現状確認と次の一手を教えてくれます。お守りみたいなコマンドです。

## ステップ 1: はじめてのセットアップ — `init`

### 1-1. Claude Code を起動する

いつもの方法で開いてください。

### 1-2. 作業フォルダに移動する

Claude Code の入力欄に、次のように打って送信します。

```
さきほど作った「マイポートフォリオ」フォルダに移動してください
```

これで作業場所が切り替わります。

> **うまくいかないとき:** 「デスクトップにある『マイポートフォリオ』フォルダはどこ?」と Claude Code に聞いてみてください。一緒に探してくれます。気軽に頼って大丈夫です。

### 1-3. セットアップのコマンドを唱える

次の文字をそのまま入力してください。コピペでも構いません。

```
/cc-portfoliokit:init
```

`init` ── イニットと読みます ── は「初期化する」の略。最初の 1 回だけ叩く呪文です。

### 1-4. ファイルが用意される

`init` は **質問をしない、お手軽コマンド** です。エンターを送ると数秒で、フォルダの中に次のものができあがります。

```
マイポートフォリオ/
├── config.md                ← サイト設定とサイト用の自己紹介
├── career/
│   ├── profile.md           ← 氏名 / 職業 / 趣味などの基本情報
│   └── work-history.md      ← 職歴・副業・活動 (このあと hearing で埋めます)
└── assets/
    └── README.md            ← 画像の置き方ガイド
```

そして Claude Code が「これからの流れ」を案内してくれます。

### 1-5. 次にやることは 3 つ

`init` の出力にも書かれていますが、次の 3 つを順番に進めます。

**① `./assets/` フォルダにアイコン画像を 1 枚入れる**

顔写真でも、似顔絵でも、お気に入りの 1 枚でも大丈夫です。ファイル名は何でも OK ── あとで自動で拾ってくれます。

> ファイルの入れ方が分からないときは、Claude Code に「`./assets/` フォルダに、デスクトップにある『私の写真.jpg』を入れて」とお願いしてみてください。

**② `./config.md` と `./career/profile.md` を開いてプロフィールを書く**

メモ帳や TextEdit、VS Code など、いつも文字を書くアプリで開いて構いません。ファイルの先頭にコメントで「ここに何を書くか」が説明してあるので、それに沿って埋めるだけです。書く中身はだいたいこんなもの:

- **氏名・職業** — `career/profile.md` の冒頭
- **サイトのタイトルやキャッチコピー** — `config.md` の冒頭
- **自己紹介** — `config.md` の `## 自己紹介 (About)` ブロック
- **連絡先** — `config.md` の `## 連絡先` ブロック。Email / GitHub / X / Instagram / LinkedIn / Facebook / YouTube / TikTok / note / Website のうち、**使うものだけ** 値を入れ、使わない `### 〇〇` ブロックは削除すれば OK

「全部書かなくちゃ」と気負わなくて大丈夫です。書いたぶんだけ HTML に出ます。

**③ `/cc-portfoliokit:hearing` で職歴・副業・活動を入れる**

これは次のステップ 1.5 で説明します。

---

## ステップ 1.5: 職歴を対話で入れる — `hearing`

`init` のあとは、職歴 (本業・副業・活動) を入れる作業です。これは **対話形式** で、Claude Code が 1 件ずつ質問してくれるので、答えていくだけで Markdown に書き込まれます。

### 1.5-1. コマンドを唱える

```
/cc-portfoliokit:hearing
```

### 1.5-2. 入り口の案内

最初に「これから何をするか」「だいたい何分くらいかかるか」を Claude Code が伝えてくれます。本業 1 社で 3〜5 分、副業や活動は 1〜2 分くらいの目安です。気合いを入れずにどうぞ。

`./assets/` に画像が入っていなかったら、ここで「画像入れてから進める? このまま続ける?」と聞いてくれます。お好きな方を選んでください。

### 1.5-3. メニュー式で 1 件ずつ追加

入り口を抜けると、次のメニューが出ます。

```
次に何を追加しますか?
  1) 本業を追加
  2) 副業を追加
  3) 活動を追加
  5) 終了する
```

選んだカテゴリの 1 件分のヒアリングが始まり、終わるとまたこのメニューに戻ってきます。「終了する」を選ぶまで何度でも追加できます。

### 1.5-4. 本業の聞かれ方 (二段構造)

本業は「会社単位」と「プロジェクト単位」の二段構えで聞かれます。

- **会社単位**: 会社名 / 在籍期間 / 役職 / ふだんやっていたこと / 全体の成果
- **プロジェクト単位** (任意): 印象に残ったプロジェクトを 1 件ずつ、PJ 名 / 使ったツール・スキル / 成果

PJ を入れたくない人 (営業や店舗スタッフなど、PJ という単位で動かない職種) は、PJ ループをまるごとスキップできます。

### 1.5-5. 副業・活動の聞かれ方 (フラット)

副業と活動は 6 問のフラット構造。

- **副業**: 案件名 / 期間 / 立場 / ふだんやっていたこと / 使ったツール・スキル / 成果
- **活動**: 活動名 / 期間 / 自分の役割 / ふだんやっていたこと / 関連スキル・道具 / 規模感

任意項目は「思いつかなければ『特になし』で大丈夫」と一言添えられるので、肩の力を抜いて答えてください。

### 1.5-6. 入れたものを直すには

メニューに `4) これまでに入れた本業・副業・活動を直す` があります。間違えたり書き換えたくなったら、ここから直せます。

> ここでも完璧主義は敵です。「**全部完璧に思い出そう** とは思わなくて大丈夫」「**書きたい分だけ書いて、終わってもいい**」が正解。後から何度でも追加・編集できます。

### 1.5-7. 完了報告

「終了する」を選ぶと、入れた件数の振り返りと、次のステップ ── `create` ── への案内が出ます。

---

## ステップ 2: ポートフォリオを完成させる — `create`

> **前提**: ここに進むのは、`init` で用意したファイルにプロフィールを書き込んで、`hearing` で職歴も入れたあとです。まだ済んでいない場合は、上のステップ 1 / 1.5 に戻ってください。

### 2-1. `create` のコマンドを唱える

次の文字を打って送信します。

```
/cc-portfoliokit:create
```

これが、初回も 2 回目以降もずっと使う「ふだん使いのコマンド」です。

### 2-2. テーマの雰囲気をちょっとだけ相談される

`create` を初めて叩くと、いきなり HTML ができるのではなく、まず **「どんな雰囲気のポートフォリオにしたいですか?」** と Claude Code が声をかけてくれます。3 つの選択肢が出るので、気軽に選んでください。

| 番号 | やること | こんな方向け |
| --- | --- | --- |
| 1 | **このまま生成する** | とにかく早く完成したい方。テンプレートの初期色 ── 青系 ── で OK |
| 2 | **テーマを決め直したい** | 色や雰囲気を自分で決めたい方 |
| 3 | **イメージがない** | 「こんな感じ」と言葉にできない方。Claude Code から案を提案してもらえます |

> **急ぎの方は「1) このまま」で構いません**。あとから何度でも変えられます。完璧に決めなくて大丈夫。

**「2) テーマを決め直したい」を選んだ場合** は、Claude Code が以下を順番に聞いてくれます。1 問ずつ短く答えるだけなので、心の準備は要りません。

- どんな雰囲気にしたい? 落ち着き / カジュアル / クリエイティブ / シンプル / ダーク のいずれか、または自由記入から選べます
- 色はどれにする? 雰囲気に合わせた候補が出ます。HEX 形式で自分で指定することも可能です
- サイトタイトルは? こちらから候補が出るので、選ぶだけでも OK
- キャッチコピーは? こちらも候補つきです
- どのセクションをどの順番で出す? 今のままで良ければそう答えるだけ

**「3) イメージがない」を選んだ場合** は、職歴の内容を Claude Code が読んで、`案 A` `案 B` `案 C` のように **方向性ごとセット** で提案してくれます。気に入ったものを選ぶだけ。「もう少しこういう感じが…」と言えば、その方向で再提案もしてくれます。

### 2-3. ポートフォリオが生成される

雰囲気の相談が終わると、`portfolio.html` が自動でできあがります。「`✅ portfolio.html を生成しました!`」というメッセージが出ればゴールです。

### 2-4. 完成を確認する

フォルダの中に **`portfolio.html`** という出来たてホヤホヤのポートフォリオファイルがあるはずです。

> **早く見たい方は:** `portfolio.html` をダブルクリック。ブラウザで自分のページがお披露目されます。

---

## ステップ 3: あとから直したくなったら — `create` をもう一度

「やっぱり職歴を 1 つ追加したい」「色を変えたい」と思ったら、もう一度 `create` を叩くだけです。

### 3-1. 同じコマンドを叩く

```
/cc-portfoliokit:create
```

### 3-2. 編集メニューが出る

Claude Code が「**お、すでにポートフォリオがありますね。どこを直しましょう?**」と気づいてくれます。

> **メモ:** コマンド名は `create` ── 作る、という意味ですね ── ですが、2 回目以降は自動で **編集モード** に切り替わります。「`init` は最初の 1 回、`create` は永遠に」と覚えてください。

### 3-3. やりたいことを選ぶ

Claude Code が、まず **6 つの大きな選択肢** を出してくれます。「全部やり直す」「ちょっとだけ変える」「とにかく提案して」などをここで選びます。

| 番号 | やりたいこと | こんなときに |
| --- | --- | --- |
| 1 | **細かい項目を変えたい** | 氏名・連絡先・職歴など、ピンポイントで直したいとき |
| 2 | **テーマを決め直したい** | 雰囲気・色・タイトル・キャッチコピーをまとめて見直したいとき |
| 3 | **色だけ変えたい** | テーマカラーとアクセントカラーだけサクッと変えたいとき |
| 4 | **内容を変えずに再生成だけしたい** | 自分で Markdown を書き換えた後に、HTML だけ作り直したいとき |
| 5 | **イメージがない、提案してほしい** | 「変えたいけど何を変えたいか言葉にできない」とき |
| 6 | **キャンセル** | やっぱりやめたとき |

> **迷ったら 5 番** が安心です。Claude Code が職歴を読んで「こんな方向性はいかがですか?」と **案 A / B / C** を出してくれます。気に入ったものを選ぶだけ。

**「1) 細かい項目を変えたい」を選んだ場合**、さらに細かいメニューが出てきます。よく使うのはこのあたり:

- サイトタイトル / キャッチコピーを変える
- テーマカラーを変える
- 自己紹介、つまり About セクションを直す
- 氏名・ふりがな・キャリア総年数を直す
- 連絡先 ── Email / GitHub などです ── を直す
- 顔写真のファイル名を変える
- **経歴を追加する** — 本業 / 副業 / 活動 から選んで追加できます
- **既存の経歴を直す** — 本業 ↔ 副業 ↔ 活動 の種別変更も可能

直したい項目を選ぶと、その項目について質問が始まります。

> **「2) テーマを決め直したい」「3) 色だけ変えたい」を選んだ場合** は、ステップ 2-2 で出てきた「雰囲気のヒアリング」と同じ流れで色や方向性を決め直せます。同じ手順なので、初回と 2 回目で迷うことはありません。

### 3-4. 反映を確認する

選んだ項目について答えると、`portfolio.html` が **その場で作り直されます**。

ブラウザで `portfolio.html` を再読み込み、つまりリロードすれば、新しい内容が見られます。「あれ、さっきと違う!」となれば成功です。

## ステップ 4: できたページを見てみる

1. 作業フォルダ「マイポートフォリオ」を開く
2. **`portfolio.html`** をダブルクリック
3. ブラウザ ── Chrome や Safari など ── でポートフォリオがお披露目

> **誰かに見せたいとき:** ファイルをそのままメールに添付して送って OK です。ホームページとして公開する方法もあります。これは別のページで案内します。

## ステップ 5: 寄り道 — Markdown を自分で開いて編集する

ここまでで完成、なのですが — 「**もう少し細かく自分でいじりたい**」「**たくさん書き換えるからメニューを 1 つずつ選ぶのが面倒**」という方のために、もう一つの編集方法があります。それが「**フォルダの中の `.md` ファイルを直接開いて書き換える**」というやり方。

> 「Markdown ってあれでしょ? 文字に印を付ける記号がいっぱいのやつ…」と身構える必要はありません。cc-PortfolioKit の `.md` ファイルは、**普通の文章の前に「## なになに」という見出しを書いてあるだけ**です。Word の見出しスタイルに似たものだと思ってください。

### 5-1. 編集できるファイルは 3 つ

```
マイポートフォリオ/
├── config.md                  ← サイトのタイトル / 色 / 自己紹介 / 連絡先など
└── career/
    ├── profile.md             ← 氏名 / ふりがな / キャリア総年数
    └── work-history.md        ← 職歴。1 社ごとに分かれて並んでいます
```

メモ帳 / TextEdit / VS Code など、**普段使っている文字編集アプリ**で開いて構いません。慣れたアプリでどうぞ。

### 5-2. ファイルの中身はこんな見た目

たとえば `career/profile.md` の中はこうなっています:

```markdown
## 氏名

山田 太郎

## ふりがな

やまだ たろう

## キャリア総年数

5 年
```

ルールは 3 つだけ:

1. **「## なになに」── シャープ 2 つ + スペース + ラベルの形 ── の下に、値を書く**
2. **見出しと値の間は 1 行空ける**
3. **`<!-- -->` で囲まれた部分はパソコン向けのメモ書き** ── 画面には出ないので無視して OK

### 5-3. 項目を「足す」「消す」「並べ替える」

cc-PortfolioKit の `.md` ファイルは、**「## なになに」のブロック単位** で動かせるように作ってあります。

**消したいとき** — その「## なになに」の行から、次の「## なになに」の手前までを **まるごと削除** すれば OK。たとえば「ふりがな」を載せたくないなら:

```markdown
## ふりがな        ← この行から

やまだ たろう       ← ここまで削除

<!-- 不要なら、... --> ← コメントも一緒に削除
```

これで「ふりがな」は HTML に出なくなります。

**足したいとき** — 好きな場所に「## 新しい項目名」を追加して、下に値を書くだけ。たとえば居住地を入れたければ:

```markdown
## 居住地

東京都
```

を、profile.md の好きな場所に差し込んで保存。

**並べ替えたいとき** — 「## なになに」のブロックごと、上下に切り貼り。HTML 上の表示順も、書いた順番に合わせて並びます。

### 5-4. 職歴ファイルの構造

職歴ファイル、つまり work-history.md は、ちょっとだけ階層が深いです。**1 社ごとに `## 会社名` のブロック**があり、その中に `### 期間` `### 役職` `### やったこと` などの **`### ` 見出し ── シャープ 3 つの形 ── のサブブロック** が並んでいます。

```markdown
## 株式会社サンプル

### 期間

2020-04 〜 2023-03 (3 年)

### 役職

ソフトウェアエンジニア

### やったこと

- 〇〇プロダクトの開発
- レビュー業務
```

ルールは profile.md と同じ。

- **会社を 1 社追加** したい → 好きな位置に `## 新しい会社名` のブロックをコピペして書き換える
- **会社を消す** → その `## 会社名` から次の `## 会社名` の手前までを丸ごと削除
- **「使用技術」だけ消したい** → その会社の `### 使用技術` ブロックだけを削除

> ファイルの末尾には「コピペ用のひな型」がコメントで残してあります。新しい職歴を足すときはそれを使うとラクです。

### 5-5. 保存したら `/cc-portfoliokit:create`

編集が終わったら、Claude Code に戻って **`/cc-portfoliokit:create`** を叩くだけ。「編集メニュー」が出るので **「1) 再生成」を選択** すると、書き換えた内容が `portfolio.html` に反映されます。

> **ヒント:** ファイルを開きながら少しずつ書き換えて、ブラウザで `portfolio.html` をリロードしながら確認すると、自分のページが目の前で育っていく感覚があって楽しいですよ。

### 5-6. 書き換えた後、形が崩れていないか心配なときは — `cleanup`

たくさん書き換えたあと「あれ、`## なになに` を消し忘れたかも」「空の見出しがそのまま残っていないかな?」と不安になったら、安心のお掃除コマンドがあります。

```
/cc-portfoliokit:cleanup
```

このコマンドは、`config.md` / `career/profile.md` / `career/work-history.md` の **形だけ** を見て、次のような「ちょっと崩れているところ」を 1 件ずつ確認しながら整えてくれます。

- **必須の見出しが消えている** — 例: `## 氏名` `## サイトタイトル` `### 種別` が無い
- **見出しだけ残って中身が空** — `### 役職` の下が空のままになっている、など
- **見出しと値の間の空行が抜けている** — 見た目が密着していて読みにくい状態
- **顔写真のファイル名が `assets/` 内のファイルと食い違っている** — 置き忘れや書き間違い
- **カラーコード ── HEX ── の書き方がおかしい**

> 🧹 **このコマンドが守る原則**: 提示された問題ごとに「直す / スキップ / 中断」を 1 件ずつ選べます。**まとめて勝手に書き換えることはしません**。中身の文章 ── たとえば「○○の業務をやった」 ── も触りません。形だけ整える、控えめなコマンドです。
>
> **`portfolio.html` には触らない** ので、`cleanup` で形を整えたあとに **`/cc-portfoliokit:create`** をもう一度叩いて HTML に反映してください。

## こんなときどうする? — よくある質問

### Q0. そもそも何から始めればいいか分からない

迷ったらまず `/cc-portfoliokit:guide` を叩いてください。フォルダの中を覗いて、いまの状況に合わせて「次に打つコマンドを 1 つだけ」教えてくれます。何も書き換えない読み取り専用の道案内なので、気軽に試して大丈夫です。

### Q1. コマンドを打ったのに何も起きない

- スペルが間違っていないか確認してください。正しいコマンドは `/cc-portfoliokit:init` / `/cc-portfoliokit:hearing` / `/cc-portfoliokit:create` / `/cc-portfoliokit:cleanup` / `/cc-portfoliokit:guide` の 5 つです。コロン `:` を忘れがちなので注意
- 半角で入力されているか確認してください。全角の `/` だと反応してくれません

### Q2. `create` を打ったら「先に init をやってね」と言われた

そのとおりです。`/cc-portfoliokit:init` でファイルを用意 → アイコン画像と `config.md` / `profile.md` を編集 → `/cc-portfoliokit:hearing` で職歴を入れる ── という流れを踏んでから、もう一度 `/cc-portfoliokit:create` を叩いてください。詳しくは ステップ 1 / 1.5 を参照。

### Q3. 質問の意味が分からない

そのまま **「分かりません」「もう少し簡単に説明して」** と Claude Code に伝えてください。別の言い方で説明し直してくれます。恥ずかしがる必要はありません、Claude Code は何度聞かれてもニコニコしています。

### Q4. 途中でやめたくなった

- 質問の途中なら「いったん中断します」と打てば止まります
- 入力ずみの内容は自動で保存されているので、次に同じコマンドを実行すれば続きから再開できます

### Q5. 変な内容を入力してしまった

慌てなくて大丈夫です。もう一度 `/cc-portfoliokit:create` を実行して編集メニューに入り、書き換えるだけ。何度でもやり直せます。

### Q6. ポートフォリオが見つからない

「`portfolio.html` というファイルはどこにある?」と Claude Code に聞いてください。すぐに教えてくれます。

### Q7. 顔写真を入れたい

1. 顔写真ファイル ── JPG や PNG などの画像形式です ── を、作業フォルダの中の **`assets`** フォルダに入れる
2. もう一度 `/cc-portfoliokit:create` を実行し、編集メニューから「顔写真のファイル名」を選んで設定する

詳しくは `templates/assets-README.md` も参考にしてください。

> 🎒 **メール / USB で配るときの注意**: `portfolio.html` だけを送ると、相手の画面で顔写真が消えてしまいます。これは HTML が「写真は `assets/` フォルダにあるよ」と参照する仕組みになっているため。配るときは **`portfolio.html` と `assets/` フォルダをセットで** 渡してください。ZIP にまとめて送るのが一番確実です。
>
> 📷 **スマホで撮った写真について**: スマートフォンで撮った写真には「撮影場所」「日時」「機種名」といった情報 ── EXIF と呼ばれます ── が一緒についていることがあります。写真の公開範囲が気になる方は、写真共有アプリの「位置情報を削除して共有」機能や、無料の EXIF 除去ツールで取り除いてから差し替えると安心です。Claude Code に「この写真の EXIF を消して」と頼んでみるのもアリ。

### Q8. `init` をもう一度やり直したい

`/cc-portfoliokit:init` をもう一度叩くと、「既にファイルがありますがどうしますか?」と聞いてくれます。

- **足りないものだけ作る** (推奨) — 編集済みの内容は守られます
- **全部上書きしてやり直す** — 注意: 書いた内容が消えます

### Q9. 副業や活動は必ず入れないとダメ?

いいえ、両方とも任意です。`/cc-portfoliokit:hearing` のメニュー画面で「本業を追加」「副業を追加」「活動を追加」「終了する」が選べるので、**追加したいカテゴリだけ選んで、不要なら終了** すれば OK です。あとから思いついたら、もう一度 `/cc-portfoliokit:hearing` を叩いて追加することもできますし、メニューの「これまでに入れた本業・副業・活動を直す」から既存のエントリを編集することもできます。

### Q10. 本業 / 副業 / 活動 の違いがよく分からない

ざっくり次の感覚で大丈夫です。迷ったら「自分が一番しっくりくる方」で選んでください。あとで変えられます。

- **本業**: フルタイムで所属している、または所属していた会社・組織
- **副業**: 業務委託・フリーランス・個人開発・顧問など、**本業以外でお金が動く** 取り組み
- **活動**: イベント運営・コミュニティ活動・OSS・登壇・執筆など、**お金が直接動かなくても胸を張れる取り組み**

### Q11. 選んだ職業を後から変えたい

`/cc-portfoliokit:create` の編集メニュー (「1) 細かい項目を変えたい」→「氏名・ふりがな・キャリア総年数を直す」のあたり) から職業も変更できます。または、`career/profile.md` をエディタで開いて `## 職業` の値を書き換えるだけでも OK です。次に `create` を実行すれば、HTML の表示ラベル ── たとえば「使用技術」が「担当業界・商材」に切り替わったり ── も新しい職業に合わせて自動で更新されます。

### Q12. 自分の職業がリストにない / 迷う

そのときは **「その他」を選んで自由記入** で OK です。たとえば「フリーランスのフォトグラファー」「主婦・育児中のキャリアブランク」「学生 (院生)」など、自分にしっくりくる言葉を書いてください。HTML の表示ラベルは「関連スキル・専門」など汎用のものに切り替わります。「これ、当てはまるかな?」と迷うくらいなら、近い職種を選んで進めてしまって大丈夫 (後から何度でも変更できます)。

### Q13. 生年月日や居住地を載せていいか迷う

`career/profile.md` には **デフォルトでは載らない** ように `## 生年月日` / `## 居住地` / `## 話せる言語` がコメントとしてのみ書かれています。書き加えるとそのまま HTML に出ます。

- **個別に PDF やメールで送るだけ** ── 信頼できる相手に直接渡す ── なら、生年月日や居住地もアリ
- **インターネットで広く公開する** ── ホームページとして上げる ── なら、居住地は「東京都」など市区町村まで、生年月日は載せない、という選び方が安全です
- 迷ったら **書かないまま生成して、必要になったとき書き足す** のが一番安全。あとから何度でも書き換えられます

### Q14. Markdown を手で直したけど、形が崩れていないか心配

**`/cc-portfoliokit:cleanup`** をどうぞ。`config.md` / `career/profile.md` / `career/work-history.md` をざっと見て、必須の見出しが欠けていないか / 空のブロックが残っていないか / 空行が変じゃないか、をチェックして 1 件ずつ「直す / スキップ」を選びながら整えてくれます。

- **HTML には触りません**。整え終わったあとに `/cc-portfoliokit:create` を叩けば、ピカピカの状態を HTML に反映できます
- **中身の文章は書き換えません**。「TypeScript」を「JavaScript」に直したり、業務内容を勝手に書き直したり、は **絶対にしない** ようになっています
- 「自動で全部直して」と言われても、影響が大きい修正だけは自動で実行し、見栄え程度の修正は確認待ちにする ── そういう安全運転のコマンドです

## それでも困ったら

このページで解決しない場合は、**Claude Code にそのまま「困っています」と伝えて** ください。状況を一緒に整理しながら手助けしてくれます。

「うまくいかないこと自体を、そのまま言葉にして伝える」のがいちばんの近道です。たとえば:

- 「`/cc-portfoliokit:create` と入力したら、`〇〇` というメッセージが出て先に進めません」
- 「ポートフォリオはできたのですが、ブラウザで開いたら真っ白でした」

このように **何をして、何が起きたか** をセットで伝えると、Claude Code がすぐに原因を一緒に探してくれます。

> エンジニアの世界には「**現象を正確に説明できれば、問題は半分解けたようなもの**」という言い回しがあります。安心して、何が起きたかをそのまま教えてください。

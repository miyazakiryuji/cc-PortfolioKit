# デスクトップアプリで cc-PortfolioKit を使う

Claude Code は **CLI 版 (黒い画面)** だけでなく、**デスクトップアプリ版** でも動きます。「黒い画面はちょっと苦手…」という方は、こちらのほうが入りやすいです。

このページでは、デスクトップアプリ版で `cc-PortfolioKit` プラグインを使うまでの手順を、できるだけかみ砕いて説明します。

> **このページの前提**
> Claude Code 自体が何者かピンと来ていない方は、先に [はじめてのClaude Code.md](./はじめてのClaude%20Code.md) を一読しておくと迷いません。

---

## デスクトップアプリ版って、CLI 版と何が違うの?

ざっくり比較すると、こんな感じです。

| | CLI 版 (黒い画面) | デスクトップアプリ版 |
| --- | --- | --- |
| 見た目 | 文字だけ。素朴。 | 普段のアプリと同じ画面。ボタンや入力欄がある。 |
| 起動 | ターミナルを開いて `claude` と打つ | アイコンをダブルクリック |
| できること | フルセット。なんでも | 普段使いには十分。CLI 版でできる大半のことはできる |
| 慣れやすさ | 慣れるまで少しコツが要る | 普段のアプリと同じ感覚 |
| プラグインの動作 | 動く | 動く (同じプラグインがそのまま使える) |

**`cc-PortfolioKit` はどちらでも同じように動きます**。ですので、好みで選んで大丈夫です。

> **どちらか迷ったら**
> はじめての方は、まずデスクトップアプリ版で雰囲気をつかんで、慣れたら CLI 版にも手を出してみる、という流れが楽です。

---

## ステップ 1: デスクトップアプリをインストールする

### 1-1. 公式ページからダウンロード

ブラウザ (Chrome や Safari) で **「Claude Code デスクトップ」** と検索し、**Anthropic (アンソロピック) 社の公式ページ** を開いてください。Anthropic は Claude を作っている会社です。

公式ページから、お使いの OS (Mac / Windows) に合ったインストーラーをダウンロードします。

> **怪しいサイトに引っかからないために**
> URL (アドレス) に `anthropic.com` という文字が入っているサイトを選んでください。それ以外の似た名前のサイトは念のため避けます。
>
> **どのファイルをダウンロードすればいいか分からない**
> Mac の場合は `.dmg` か `.pkg`、Windows の場合は `.exe` というファイルが多いです。OS の選択肢が並んでいたら、自分のパソコンの OS を選んでください。

### 1-2. インストーラーを起動する

ダウンロードした **インストーラー (セットアップ用のファイル)** をダブルクリックすると、インストール画面が出てきます。

- **Mac**: 「アプリケーション」フォルダにドラッグして配置するタイプが多いです。
- **Windows**: 「次へ」「次へ」と進んで「インストール」を押します。

途中で「**このアプリは安全ですか?**」「**インストールしてもいいですか?**」と確認画面が出たら、**OK / 許可** を選んでください。

> **「開発元が未確認です」と Mac で表示される**
> 一度ダウンロードフォルダで右クリック → 「開く」を選ぶと、未確認警告を回避してインストールできます。それでもダメな場合は、「システム設定」 → 「プライバシーとセキュリティ」 を確認してみてください。

### 1-3. 初回起動とサインイン

インストールが終わったら、Claude Code アプリを起動します。

- **Mac**: Launchpad (ロケットのアイコン) や Spotlight (`Command` + `Space`) から起動
- **Windows**: スタートメニューから起動

初回起動時には、**Anthropic アカウントへのサインイン** を求められます。ブラウザが自動で開いて、メールアドレスとパスワードでログインする流れです。

> **アカウントを持っていないとき**
> サインイン画面の中に「新規登録」「サインアップ」のリンクがあります。そこからメールアドレスを使って登録できます。
>
> **会社のメールアドレスを使うべき? 個人のを使うべき?**
> どちらでも使えますが、**プライベートのポートフォリオを作るなら個人メールアドレス** がおすすめです。

## ステップ 2: 作業フォルダを開く

Claude Code は、「**いま、どこのフォルダで作業しているか**」を覚えながら動きます。なのでまず、**ポートフォリオを保存するフォルダ** をひとつ用意して、それをアプリに教えてあげる必要があります。

### 2-1. デスクトップに作業フォルダを用意する

普段どおりの操作で、デスクトップに新しいフォルダを作ってください。

- **Mac**: デスクトップで右クリック → 「新規フォルダ」
- **Windows**: デスクトップで右クリック → 「新規作成」→「フォルダー」

名前は分かりやすいもの (例: `マイポートフォリオ`) でかまいません。

### 2-2. Claude Code アプリでそのフォルダを開く

アプリの画面に、たいてい次のような選択肢があります (バージョンによって少し見た目が違うかもしれません)。

- **「フォルダを開く」**
- **「Open folder」**
- **「プロジェクトを開く」**

このボタンを押して、さきほど作った **`マイポートフォリオ`** フォルダを選びます。

> **どこのボタンか分からない**
> アプリ左上に「ファイル」メニューがあれば、その中に「フォルダを開く」が入っていることが多いです。
> あるいは、画面下部の入力欄に **「マイポートフォリオというフォルダを開いてください」** と日本語で頼んでも動くことが多いです。

フォルダを開くと、画面の側面に **そのフォルダの中にあるファイル一覧** が表示されます。最初は空っぽで OK です。

## ステップ 3: プラグインを取り込む

ここから本題。**`cc-PortfolioKit` プラグイン** をデスクトップアプリに認識させます。

### 3-1. プラグインの場所を確認する

`cc-PortfolioKit` プラグインがパソコンのどこに保存されているかを把握しておきます。

たとえば、ダウンロードしたフォルダが次のような場所だとします。

```
/Users/あなたのユーザー名/Developer/work/Idris-co/tools/cc-PortfolioKit
```

このパス (= 道のり) をあとで使いますので、**Finder (Mac) や エクスプローラー (Windows)** で開いて、場所を確認しておいてください。

> **「パス」って何?**
> パソコンの中のフォルダの位置を、住所のように **`/` (スラッシュ) でつないだ文字列** で表現したものです。Mac だと `/Users/...`、Windows だと `C:\Users\...` のように書きます。
>
> **パスをコピーするコツ**
> - **Mac**: フォルダを右クリック → `Option` キーを押しながら「パスをコピー」が選べます。
> - **Windows**: フォルダのアドレスバーをクリックすると、その場でパスが文字列として見えます。

### 3-2. プラグインインストールコマンドを入力する

Claude Code アプリの **入力欄** (画面の下のほうにあるチャット入力ボックス) に、次のコマンドを入力します。

```
/plugin install /Users/あなたのユーザー名/Developer/work/Idris-co/tools/cc-PortfolioKit
```

> **コマンドはコピー & ペーストでもOK**
> 上の文字列をそのままコピーし、自分の `あなたのユーザー名` の部分を書き換えて貼り付ければ十分です。

入力できたら **送信ボタン** または `Enter` キー で実行。

うまくいけば、「プラグインを追加しました」「インストールが完了しました」のようなメッセージが返ってきます。

> **「コマンドが見つかりません」と返ってきたら**
> プラグイン機能が古いバージョンで使えない可能性があります。アプリを最新版にアップデートしてから、もう一度試してみてください。アップデートのやり方はアプリのメニュー → 「Claude Code について」 → 「アップデートを確認」のあたりに入っています。
>
> **「パスが見つかりません」と返ってきたら**
> パス (フォルダの場所) が間違っています。Finder / エクスプローラーでもう一度 `cc-PortfolioKit` フォルダの正しい場所を確認してください。

## ステップ 4: 実際に使ってみる

ここまで来れば準備完了です。

このプラグインで覚えるコマンドは **2 つだけ** です。

| コマンド | 役割 | 叩くタイミング |
| --- | --- | --- |
| `/cc-portfoliokit:init` | フォルダ作成 + 氏名・キャリアのヒアリング | **最初の 1 回だけ** |
| `/cc-portfoliokit:create` | ポートフォリオ (`portfolio.html`) の生成 / 編集 | `init` の後に、何度でも |

### 4-1. 最初に「init」を叩く

入力欄に、まずはこの **呪文** を入れて送信してみてください。

```
/cc-portfoliokit:init
```

`init` (イニット) は「**初期化する**」の略。最初の 1 回だけのコマンドです。お名前・キャリア年数・職歴を順番に質問してくれます。

> **質問の意味が分からなければ「分かりません」と返事するだけで OK**
> Claude Code は、もっとかみ砕いて言い直してくれます。専門知識が必要な質問は基本的に出てこないので、安心してください。

### 4-2. 次に「create」を叩く

ヒアリングが終わったら、続けて

```
/cc-portfoliokit:create
```

を送信。これで `portfolio.html` が出来上がります。

`create` (クリエイト) は「**作る**」のコマンドですが、2 回目以降は **編集モード** に自動で切り替わるので、これからの編集も全部このコマンドで完結します。

具体的な対話の流れや、出来上がったあとの手順は **[手順書.md](./手順書.md)** に詳しくまとまっています。

## デスクトップアプリならではの便利機能

CLI 版にはなく、デスクトップアプリ版だからこそ使える機能をいくつか紹介します。

### ファイル一覧をクリックで開ける

画面の左側に表示されているファイル一覧から、`portfolio.html` などをクリックすると、その中身を直接見られます。「いまどんなファイルが出来上がっているか」が一目瞭然です。

### 出来上がった HTML をすぐ確認できる

`portfolio.html` を右クリック → 「ブラウザで開く」のような操作で、生成されたポートフォリオをその場で確認できます。

> **クリックでブラウザが開かない**
> ファイル一覧で `portfolio.html` を選び、Finder / エクスプローラーに切り替えて、そこでダブルクリックする方法もあります。

### スクリーンショットを貼ると認識してくれる

「**この画面のこの部分を直したい**」という依頼を、スクリーンショットを貼り付けて伝えることができます。Claude Code 側で画像を見て理解してくれるので、文章だけで説明しづらいときに便利です。

## CLI 版と併用したい人へ

「普段はデスクトップアプリ、たまに CLI も使う」というスタイルも問題なくできます。

**プラグインは一度インストールすれば、CLI 版・デスクトップアプリ版のどちらからでも使えます** (※ 設定ファイルが共有されているため)。なので、デスクトップ版でインストールしたあと、CLI 版を起動したらすでに `/cc-portfoliokit:create` が使える状態になっています。

逆もまた然りで、CLI 版でインストール済みなら、デスクトップアプリでもそのまま使えます。

> **両方で「あれ、使えない?」となるパターン**
> プラグインを **異なるユーザーアカウント** でインストールしている場合は、共有されません。「いつも使っているのと同じユーザー」で操作しているか、念のため確認してください。

## 困ったときの逃げ場

うまくいかないときは、まず深呼吸して以下を試してみてください。

1. **Claude Code アプリを一度終了して起動し直す** (たいていの不具合はこれで直ります)
2. それでもダメなら、**[トラブルシューティング.md](./トラブルシューティング.md)** を確認
3. それでもダメなら、Claude Code に **「こういう状態で、こうしたかったけど、こうなりました」と日本語でそのまま相談**

エラーが英語で出てきても、コピーしてアプリに貼り付けて「これってどういう意味?」と聞けば、すぐに翻訳して説明してくれます。
